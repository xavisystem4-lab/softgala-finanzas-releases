# SoftGala Finanzas — instaladores

## Descarga directa

- **Instalador (.zip, recomendado):** https://github.com/xavisystem4-lab/softgala-finanzas-releases/raw/main/instaladores/SoftGalaFinanzas-Setup-1.2.0.zip
  Descomprime y ejecuta `SoftGalaFinanzas-Setup-1.2.0.exe`.
- **Instalador (.exe):** https://github.com/xavisystem4-lab/softgala-finanzas-releases/raw/main/instaladores/SoftGalaFinanzas-Setup-1.2.0.exe

Si Windows muestra «Windows protegió su PC», elige *Más información → Ejecutar de todas formas* (el instalador aún no tiene firma digital).

Aquí se publican los instaladores de **SoftGala Finanzas** para Windows 10 y Windows 11 (64 bits).

- El instalador más reciente está en la carpeta [`instaladores`](instaladores) y su versión en [`latest.json`](latest.json).
- La aplicación usa este repositorio para su botón **Actualizar versión**: lee `latest.json`, descarga el instalador y verifica su huella SHA-256 antes de instalarlo.

El instalador es autocontenido: no requiere instalar .NET ni otros programas.
