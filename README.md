# SoftGala Finanzas — instalador

## ⬇ Descargar

**https://github.com/xavisystem4-lab/softgala-finanzas-releases/raw/main/instaladores/SoftGalaFinanzas-Setup.exe**

Este enlace siempre descarga la versión más reciente. Versión actual: 1.2.0

- Windows 10 (versión 1809 o posterior) y Windows 11, 64 bits. No requiere instalar nada más.
- Si Windows muestra «Windows protegió su PC», elige *Más información → Ejecutar de todas formas* (el instalador aún no tiene firma digital).
- La aplicación se actualiza sola con el botón **Actualizar versión**.
