# SoftGala Finanzas — instaladores

Aquí se publican los instaladores de **SoftGala Finanzas** para Windows 10 y Windows 11 (64 bits).

- El instalador más reciente está en la carpeta [`instaladores`](instaladores) y su versión en [`latest.json`](latest.json).
- La aplicación usa este repositorio para su botón **Actualizar versión**: lee `latest.json`, descarga el instalador y verifica su huella SHA-256 antes de instalarlo.

El instalador es autocontenido: no requiere instalar .NET ni otros programas.
